# 0012 — Keep the copy with a meaningful name, not the camera-generated one

- **Priority**: High — `clean` can silently drop the name the user typed by hand
- **Batch**: keep-policy
- **Depends**: —
- **Files**: `src/media_dedup/plan/keeper.py`, `src/media_dedup/plan/copy_names.py`, `src/media_dedup/config/settings.py`, `src/media_dedup/config/templates/config.toml.j2`, `src/media_dedup/report/templates/report.html.j2`, `tests/unit/test_keeper.py`, `README.md`, `README_FR.md`

## Context

Byte-identical copies share their pixels and EXIF, but **not their name or folder**. With
`Mariage 2015\Marie et Paul.jpg` and `DCIM\100CANON\IMG_1234.jpg`, today's rank
(`KeepPolicy.rank`: protected > preferred > not a copy name > oldest mtime > shortest path >
alphabetical) may keep `IMG_1234.jpg` (older or shorter). The content survives, but the name
typed by the user, and the curated album it sat in, are deleted. This is exactly the
information users fear losing ("est-ce vraiment un doublon ?").

## Proposal

- New criterion right after "not a copy name": **the name is not generated by a device or
  app**. Case-insensitive patterns on the stem, defaults such as `IMG_\d+`, `IMG-\d{8}-WA\d+`
  (WhatsApp), `DSC[NF_]?\d+`, `P\d{7}` (Panasonic/Olympus), `PXL_\d{8}_\d+` (Pixel),
  `\d{8}_\d{6}` (Samsung), `VID_\d+`, `MVI_\d+`, `GOPR\d+`, `DJI_\d+`, `Screenshot_.*`,
  UUID/hex names (iCloud exports).
- Configurable in `config.toml` (`[keep] generated_names = [...]`, defaults in the template),
  validated as regular expressions.
- To decide during implementation: a weaker, second criterion on generic *folder* names
  (`DCIM`, `Camera`, `100CANON`, `WhatsApp Images`, `Download(s)`, `Import`). It must stay
  deterministic and explainable.
- Show **why** each keeper won (protected / preferred / meaningful name / oldest / …) in the
  report and the pairs table: a visible reason builds trust.

## Acceptance

- [ ] A meaningful name beats a generated one, below protected / preferred / copy-name.
- [ ] Patterns overridable in `config.toml`; invalid regex → `ConfigError` with a tip.
- [ ] The report shows the keep reason per group.
- [ ] README + README_FR updated (safety table "Which copy is kept"); `.po` translated.
